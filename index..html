How to Get a Free Public Link

Option 1: Netlify (Easiest - 1 Minute)

  1. Go to Netlify.com and sign up/log in for free.
  2. Click "Add new site" -> "Deploy manually".
  3. Drag and drop this index.html file into the upload box.
  4. Netlify will instantly generate your live website link!

Option 2: GitHub Pages (Free Permanent Link)

  1. Create a free account on GitHub.com.
  2. Create a new public repository named sk-education.
  3. Upload this index.html file.
  4. Go to Settings -> Pages, set source to main branch and click Save.
  5. Your site link will be ready at: username.github.io/sk-education
